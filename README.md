# Dhaaga Studio CRM

A centralized CRM platform built for **Dhaaga Studio** to manage business leads, discover new opportunities, and streamline client acquisition.

## Features

- **Lead Management** – Add, organize, update, and track business leads.
- **Business Radar** – Discover newly registered companies and potential business opportunities.
- **Industry Filtering** – Organize prospects by industry and business category.
- **Lead Qualification** – Prioritize prospects based on business potential.
- **Outreach Tracking** – Monitor lead status and follow-up activities.
- **CSV Import/Export** – Manage bulk lead data.
- **Business Intelligence** – Collect and organize publicly available business information.
- **Automated Discovery** – Scheduled workflows for identifying new business opportunities.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Supabase
- PostgreSQL
- GitHub Actions
- Vercel

## Getting Started

```bash
git clone https://github.com/Aryanboii/DhaagaStudio-CRM.git

cd DhaagaStudio-CRM
```

Configure your Supabase credentials in `config.js` and run the project using a local development server.

## Project Purpose

Dhaaga Studio CRM is designed to simplify business development by combining lead management, business discovery, and outreach tracking in one platform.
